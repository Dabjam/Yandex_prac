# Сервис учета транспортных поездок

## Назначение

Сервис предназначен для автоматизации процессов учета пассажирских и грузовых транспортных поездок, распределения транспортных средств, контроля статусов рейсов и предварительного расчета стоимости поездок.

## Целевая аудитория

- Диспетчеры и логисты транспортных компаний;
- Водители транспортных средств;
- Клиенты и пассажиры сервиса.

## Предметная область

Транспортная логистика, пассажирские перевозки и учет работы автопарка предприятия.

## Основные сущности

- **Пользователь** (клиент, водитель, диспетчер);
- **Транспортное средство** (марка, госномер, вместимость, статус готовности);
- **Маршрут** (начальная и конечная точки, протяженность в км, базовый тариф);
- **Поездка** (дата/время, назначенный транспорт, водитель, статус поездки).

## Основные функции

- Расчет предварительной стоимости поездки на основе расстояния и тарифа;
- Проверка доступности и вместимости транспортного средства под заказ;
- Определение и обновление текущего статуса рейса (запланирован, в пути, завершен, отменен);
- Управление данными пользователей, маршрутов и автопарка;
- Отслеживание назначенного маршрута и времени в пути.

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение реляционной базы данных (PostgreSQL) и настройка Django ORM;
- реализация аутентификации, авторизации и разграничения прав пользователей;
- разработка REST API для взаимодействия с внешними сервисами и приложениями;
- контейнеризация приложения с помощью Docker;
- настройка автоматического тестирования (Pytest) и процессов CI/CD.
